The Shiftvert app

  • No network code

    There's no networking code at all, so nothing is uploaded and there's no account to make.

  • Only the files you give it

    It reads just the files you drop or pick, and saves results as new files, so originals are never overwritten.

  • Minimal permissions

    It doesn't need Accessibility or Full Disk Access. macOS may ask once to let it use your Desktop, Documents or Downloads folder, so it can save results next to your files.

  • Only Apple's built-in tools

    Conversions use macOS's own frameworks and tools, with no third-party code.

  • Strips hidden details

    Zip leaves out “downloaded from” info, and Strip EXIF removes a photo's location and camera data.

  • Open source

    It's MIT licensed, so you can read every line on GitHub. Each release lists the SHA-256 checksum of Shiftvert.zip, so you can check your download is the real one.

The macOS warning

  • Why macOS says it couldn't check Shiftvert

    Apple only checks apps from developers who pay for its Developer Program ($99 a year) and send every version in for an automated malware scan. Shiftvert is a free project outside that program, so the message means “not checked by Apple”, not “malware found”. All of its code is public, so anyone can read it.

  • When to click Open Anyway

    Only for apps you got from their real source. For Shiftvert that's shiftvert.com or github.com/roiegold/shiftvert. Never do it for an app a pop-up or a stranger asked you to install.

Almost there

  1. Open your Downloads folder (in Chrome, click Shiftvert.zip first) and drag Shiftvert into Applications.
  2. Double-click it there. If macOS says it couldn't check it for malware, that's expected: click Done.
  3. Click Open Privacy & Security, scroll down to Security and click Open Anyway, then confirm with Touch ID or your password.
